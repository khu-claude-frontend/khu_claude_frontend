# 08 날짜·시각 포맷 유틸

## 목표

API의 날짜·시각 형식을 화면 표기로 바꾸는 순수 Dart 함수를 만든다.

## 할 일

- [ ] 입력 형식 파싱: ISO 8601 일시(`2026-10-23T14:20:00+09:00`), 날짜(`YYYY-MM-DD`), 시간(`HH:mm`)
- [ ] 날짜 표기는 `YYYY.MM.DD` 하나로 쓰고 시각은 보여주지 않는다
- [ ] 모든 시각은 KST 기준이다. 기기 시간대가 달라도 KST로 표시한다(`DateTime.parse`는 offset이 있으면 UTC로 바꾼다)
- [ ] 이용 시간 표기: `09:00 – 22:00`. 24시간(`open == close`)은 `00:00 – 24:00`, 자정을 넘기는 시간(`close < open`) 처리

## 완료 조건

- 시간대가 다른 환경, 자정 넘김, 24시간 경우를 포함한 Unit Test가 있다
