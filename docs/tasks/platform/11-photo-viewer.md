# 11 사진 크게 보기 화면

## 목표

후보 상세(US-04)와 관리자 공간 상세(AD-04)가 같은 방식으로 여는 전체 화면 사진 뷰어를 만든다.

## 할 일

- [ ] 입력: 사진 목록(`url`, `tag`)과 시작 위치
- [ ] 검은 배경 전체 화면, 누른 사진부터 연다
- [ ] 좌우로 밀어 이전·다음 사진
- [ ] 위쪽 가운데 `1 / 4` 위치 표시, 아래에 태그 이름(태그 없는 사진은 표시하지 않음)
- [ ] 왼쪽 위 닫기(×) 또는 아래로 밀어 닫기

## 완료 조건

- 시작 위치, 넘기기, 닫기에 대한 Widget Test가 있다

## 참고

- 화면 설계서 AD-04 C, US-04 2번 항목
- API 명세 3.2 Space `photos`
