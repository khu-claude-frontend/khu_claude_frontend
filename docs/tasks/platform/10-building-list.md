# 10 건물 모델과 건물 목록·검색 위젯

## 목표

출발 건물 선택(US-03 B)과 공간 등록의 건물 선택 시트(AD-03)는 같은 목록이다. 모델과 목록 위젯을 `lib/core/`에 하나로 만든다.

## 할 일

- [ ] `Building` 모델: `id`, `name`, `lat`, `lng`
- [ ] 목록 위젯: 상단 검색 필드 + 건물 행
  - 입력 즉시 이름으로 필터, 지우면 전체 목록
  - 가나다순
  - 행을 탭하면 선택 결과를 돌려준다. 확인 버튼은 없다
- [ ] 전체 화면(US-03 B)과 바텀시트(AD-03) 양쪽에 넣을 수 있는 형태
- [ ] 데이터 조회는 하지 않는다. 사용자는 U1(공개 공간이 있는 건물만), 관리자는 A3(전체 건물)로 엔드포인트가 달라서 각 Feature의 Repository가 맡는다

## 완료 조건

- 검색 필터, 행 선택에 대한 Widget Test가 있다
