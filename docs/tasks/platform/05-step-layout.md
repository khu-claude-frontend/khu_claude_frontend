# 05 단계형 화면 레이아웃

## 목표

검색 조건(US-01·02)과 공간 등록(AD-03)이 함께 쓰는 단계형 화면 틀을 만든다. 다른 화면도 쓰는 공통 여백·하단 CTA 영역을 같이 정한다.

## 할 일

- [ ] 화면 공통 틀: 좌우 20, 제목 아래 24, 하단 CTA 영역(상단 16 + 세이프 에어리어 34)
- [ ] 390 너비보다 넓은 화면(데스크톱 브라우저)에서 보여줄 방식 결정 후 반영
- [ ] 단계형 틀: 뒤로가기 + 상단 진행 바(숫자 없음) + 질문형 H1 + Body 부제 + 내용 + 하단 Primary CTA 1개
- [ ] CTA 비활성 상태 지원(필수값이 비면 오류 문구 없이 비활성)
- [ ] 단계 전환 애니메이션: 좌→우 슬라이드(US-01 Check Point 1번)

## 완료 조건

- 진행 바 비율, CTA 활성·비활성에 대한 Widget Test가 있다
- 390×844 기준으로 US-01 A 시안과 여백이 맞는다
