# 04 공통 컴포넌트: 바텀시트·상태 배지·별점·숫자 스테퍼

## 목표

03에 이어 나머지 공통 컴포넌트를 만든다.

## 할 일

- [ ] 바텀시트: 반경 24, 상단 핸들, 질문형 제목
  - 하나를 고르는 시트는 누르면 바로 닫는다(건물·층·조사자)
  - 여러 값을 맞추는 시트는 '확인'으로 닫는다(이용 가능 시간)
  - 바깥을 누르거나 아래로 내려 닫으면 이전 값을 그대로 둔다
  - 목록이 긴 시트는 화면 위쪽까지 올라오는 큰 시트로 연다
- [ ] 상태 배지: `공개`(Positive), `비공개`(Gray), `재조사 요청 N`(Primary)
- [ ] 별점
  - 표시: Gold로 채운 별 + 회색 빈 별, `★ 4.6 (32)` 형식
  - 입력: 1~5 탭, 누른 점수까지 Gold로 채움(US-07 A)
- [ ] 숫자 스테퍼: −/+ 버튼, 최솟값·최댓값에서 해당 버튼 비활성
  - 큰 숫자 중심형, 버튼 52(US-01 C 인원 1~10)
  - 행 안에 들어가는 작은 형태(AD-03 테이블 수·최대 인원·충전 테이블)

## 완료 조건

- 시트 닫힘 규칙, 스테퍼 경계값, 별점 입력에 대한 Widget Test가 있다
