# 03 공통 컴포넌트: 버튼·옵션 행·칩·입력 필드·카드

## 목표

여러 화면이 함께 쓰는 기본 컴포넌트를 `lib/core/widgets/`에 만든다.

## 할 일

- [ ] 버튼: 높이 56, 반경 12. Primary / Secondary / Disabled
- [ ] 옵션 행: 높이 60, 반경 14
  - 단일 선택(빈 라디오 → Primary Tint 배경 + Primary 테두리 + 체크): US-01 B
  - 다중 선택, 보조 문구 포함: US-02 B
- [ ] 칩: 높이 36, 반경 full. 기본 / 선택됨(Primary 배경 + 체크). 다중 선택(US-02 A, AD-03 목적)과 단일 선택(AD-02 필터, AD-03 소음) 모두 지원
- [ ] 입력 필드: 높이 56, 반경 12, 플레이스홀더
  - 여러 줄 입력 + 글자 수 카운터(`48 / 200`) 변형: US-07 후기 200자, 재조사 300자, AD-03 장점·단점 40자, 비고 100자
- [ ] 카드: 반경 16, 내부 여백 16
- [ ] 모든 터치 영역 44 이상

## 완료 조건

- 컴포넌트마다 상태별 Widget Test(선택·비활성·글자 수 표시)가 있다
