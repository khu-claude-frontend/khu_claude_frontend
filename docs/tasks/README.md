# 작업 목록

## A — 기반 구조

1. 폴더 구조와 패키지 세팅
2. 디자인 토큰: 컬러·Pretendard 타이포·간격·반경 `AppTheme`
3. 공통 컴포넌트: 버튼·옵션 행·칩·입력 필드·카드
4. 공통 컴포넌트: 바텀시트·상태 배지·별점·숫자 스테퍼
5. 단계형 화면 레이아웃(진행 바 + 질문형 H1 + 하단 CTA 영역)
6. API Client와 RFC 9457 에러 파싱
7. 공용 코드값(enum)과 화면 표시 문구 대응
8. 날짜·시각 포맷 유틸
9. 라우터 골격(사용자·관리자 경로 분리, 화면 간 라우트 이름 확정)과 `dependencies.dart` 조립
10. 건물 모델과 건물 목록·검색 위젯(US-03·AD-03 공용)
11. 사진 크게 보기 화면(US-04·AD-04 공용)
12. 카카오맵 JS SDK 연동 래퍼(핀·경로·현재 위치 오버레이)
13. 테스트 헬퍼와 Integration Test 셋업
