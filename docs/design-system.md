# 디자인 시스템

## 1. 컬러

경희대학교 교색 기준. Primary 면적은 최소로 쓴다.

| 토큰 | 용도 | HEX | PANTONE |
| --- | --- | --- | --- |
| Primary | 경희레드 | `#A40F16` | 201C |
| Primary Pressed | 눌림 상태 | `#8B0D13` | — |
| Primary Tint | 선택 배경 | `#FBEDEE` | — |
| Gold | 별점 전용 | `#C3A353` | 872C |
| 경희블루 | 현재 위치 | `#0D326F` | 295C |
| Positive | 공개 | `#0E8A5F` | — |
| Gray 900 | 본문 | `#191F28` | — |
| Gray 700 | 보조 | `#4E5968` | — |
| Gray 500 | 캡션 | `#8B95A1` | — |

### 컬러 사용 규칙

- Primary(경희레드)는 화면당 CTA 1개, 선택 상태, 핵심 링크. 이 3곳에만 쓴다.
- 골드는 별점 전용, 경희블루는 지도의 현재 위치 전용이다.
- 본문 텍스트는 Gray 900, 보조는 Gray 700, 캡션은 Gray 500으로 고정한다.

## 2. 타이포그래피

Pretendard 단일 서체, 7단계로 고정한다. 자간은 -1~-2%.

| 단계 | Size / Weight / Line height | 용도 | 예시 |
| --- | --- | --- | --- |
| H1 | 24 / 700 / 34 | 화면 질문 제목 | 여기서 출발할까요? |
| H2 | 20 / 700 / 28 | 카드·섹션 제목 | 중앙도서관 4층 열람실 |
| H3 | 17 / 600 / 24 | 항목 제목·내비 | 이용 가능 시간 |
| Body1 | 15 / 400 / 22 | 본문·설명 | 현재 위치를 기준으로 가까운 공간을 찾아요 |
| Body2 | 14 / 400 / 20 | 보조 정보 | 도보 6분 · 직선 400m · 테이블 10개 |
| Label | 13 / 500 / 18 | 칩·배지·필드 라벨 | 콘센트 · 조용함 |
| Caption | 12 / 400 / 16 | 메타 정보 | 최근 수정 2026.10.02 |

### 타이포 위계

- 7단계 외의 스타일은 쓰지 않는다.
- 한 화면에 H1은 1개(질문형 제목)만 둔다. 카드·섹션 제목은 H2, 리스트 항목·내비 제목은 H3이다.
- 위계를 두 단계 이상 건너뛰어 쓰지 않는다.
- 날짜는 모든 화면에서 `2026.10.02`처럼 `YYYY.MM.DD` 하나로 쓰고, 시각은 보여주지 않는다.

## 3. 간격 · 반경

4pt 그리드, 390 너비 기준.

### 간격

| 값 | 용도 |
| --- | --- |
| 4 | 텍스트 줄 간 |
| 8 | 요소 내부 |
| 12 | 요소 간 |
| 16 | 카드 내부 |
| 20 | 화면 좌우 여백 |
| 24 | 제목 아래 · 항목 간 |
| 32 | 섹션 간 |

### 반경

| 값 | 대상 |
| --- | --- |
| 12 | 버튼 · 입력 |
| 14 | 옵션 |
| 16 | 카드 |
| 24 | 바텀시트 |
| full | 칩 |

### 간격 · 여백 규칙

- 화면 좌우 20, 제목 아래 24, 섹션 간 32, 요소 간 12, 카드 내부 16.
- 리스트 행 높이는 1줄 56, 2줄 64다.
- 행 안의 제목–보조 텍스트 간격은 4, 안내 항목 사이는 24.
- 하단 CTA 영역은 상단 16 + 세이프 에어리어 34로 고정한다.

## 4. 컴포넌트

실측 크기 기준이며, 터치 영역은 44 이상이다.

| 컴포넌트 | 높이 | 반경 | 상태·변형 |
| --- | --- | --- | --- |
| 버튼 | 56 | 12 | Primary / Secondary / Disabled |
| 옵션 행 | 60 | 14 | 기본(빈 라디오) / 선택(Primary Tint 배경 + Primary 테두리 + 체크) |
| 칩 | 36 | full | 기본 / 선택됨(Primary 배경) |
| 입력 필드 | 56 | 12 | 플레이스홀더 |
| 카드 | — | 16 | — |
| 바텀시트 | — | 24 | — |

- 상태 배지: `공개`(Positive), `비공개`(Gray), `재조사 요청 N`(Primary)
- 별점: Gold로 채운 별 + 회색 빈 별
- 모든 터치 영역은 44 이상이다.

## 5. 프레임 · 설계서 표기

- 모바일 390×844 기준으로 설계하고, 시안은 66%로 축소해 표기한다.
- 관리자 화면도 모바일 웹이므로 같은 프레임·컴포넌트를 쓴다.
- 시안 위 번호 배지(`#E8474C`)는 우측 설명 표와 1:1로 대응하며, 서비스 UI에는 쓰지 않는다.

## Check Point

1. 교색은 경희대학교 UI 디자인규정의 주색(경희레드 PANTONE 201C, R164 G15 B22)을 기준으로 하고, 보조로 경희골드 PANTONE 872C · 경희블루 PANTONE 295C를 쓴다.
2. One thing per page: 입력·선택은 한 화면에 한 가지, 하단 Primary CTA는 1개만 둔다. 후보도 목록 없이 순위대로 한 곳씩 보여준다. H1은 한 줄 질문형, 설명 항목은 1 · 3 · 5개로 쓴다.
3. 범위는 경희대학교 국제캠퍼스(용인)로 한정하며, 오류 문구·통신 오류 재시도 화면은 이번 설계에서 제외한다.
4. 지도는 네이버 지도 SDK로 결정했다. SDK 기본 마커·경로는 쓰지 않고 경희레드 핀·경로, 경희블루 현재 위치로 오버레이한다(US-06).
5. 사용자는 계정 없이 기기 쿠키 세션으로 별점·재조사 요청의 중복만 막는다. 관리자는 Google 로그인 + 관리자 명단(허용 목록)으로 들어오며, 모든 관리 작업에 계정 이름이 작업자로 남는다.
